# ⚡ Getting Started

## Clone the repository

```bash
git clone https://github.com/anuragrajpoott/portfolio.git
```

## Navigate to the project

```bash
cd portfolio
```

## Install dependencies

```bash
npm install
```

## Run development server

```bash
npm run dev
```

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

# 🎨 Design Philosophy

The portfolio follows a minimalist and recruiter-focused design philosophy built around:

- Simplicity
- Readability
- Consistency
- Accessibility
- Performance
- Responsive Design

The goal is to let the projects and experience stand out while providing a polished, modern, and enjoyable browsing experience.

# 🚀 Performance

The website is built with performance in mind.

- Fast page loads
- Lazy-loaded images
- Responsive layouts
- Accessible components
- Semantic HTML
- Smooth scrolling
- Lightweight animations
